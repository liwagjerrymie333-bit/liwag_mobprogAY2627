Laboratory 1: In newsfeed_card.dart, I worked on making the post image more flexible by using hasImage to check if a post has an image or not. If there is an image, it will be displayed, and if there isn't, the image section won't appear. I also added the owl image as the default whenever no image path is provided, while keeping a placeholder with an icon and text in case the image fails to load. I also separated the avatar and the love button with its heart count into their own widgets to make the code more organized. Lastly, I used flutter_screenutil to make the UI adjust properly to different screen sizes.
